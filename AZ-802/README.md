# AZ-802 Drill

A compact, public-safe study notebook for Microsoft AZ-802 / Windows Server hybrid administration.

## Goal

Turn real study sessions into short drills that can be reviewed quickly before an exam or technical interview.

Each topic should follow the same structure:

1. **Core idea**
2. **Scenario**
3. **Diagnosis**
4. **Commands**
5. **Interpretation**
6. **Repair / recommended action**
7. **Exam trap**
8. **Interview question**
9. **One C1/CAE phrase**

## Public-safety rule

All examples are anonymized. Use only neutral lab values such as:

- domain: `contoso.local`
- servers: `DC01`, `DC02`, `FS01`, `HV01`
- networks: `10.10.0.0/16`
- users: `student01`, `admin01`

Do not publish real names, domains, hostnames, IP addresses, VLANs, e-mail addresses, credentials, tenant IDs, firewall rules, or reconstructable production topology.
